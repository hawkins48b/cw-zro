# SvelteKit 3 and Vite 8 toolchain

- **Date:** 2026-11-05
- **Branch:** task/72-toolchain
- **Issue:** [#72](https://github.com/hawkins48b/cw-zro/issues/72)
- **Status:** Delivered on `develop`, not in production yet

## Summary

The build toolchain was a major behind, and several audit findings sat in it. The goal was to upgrade it together, including the Capacitor build.

**Delivered:** all six packages are on their latest major, `npm audit` findings drop from 13 to 11, and the npm crash from [#71](2026-11-05-71-in-range-updates.md) is gone. Pages render the same as on `develop`, with one small fix to the ammo selector. Paraglide, Skeleton, Svelte, Tailwind and `js-ballistics` did not move.

| Package | Before | After |
|---------|--------|-------|
| `@sveltejs/kit` | 2.70.4 | 3.1.1 |
| `vite` | 7.3.7 | 8.3.6 |
| `@sveltejs/vite-plugin-svelte` | 6.2.4 | 7.3.1 |
| `@sveltejs/adapter-static` | 3.0.11 | 4.0.1 |
| `vitest` | 4.1.12 | 5.1.0 |
| `jsdom` | 28.1.0 | 31.0.0 |

The issue named `jsdom` 30.1; 31.0.0 is the latest.

### Effect on users

- **Version check:** Kit 3 fetches `_app/version.json` when the tab regains focus and once an hour. The request stays on the same origin, and the app does not use the result.
- **Older browsers:** the build target rises from Safari 16.0, Chrome 107 and Firefox 104 to Safari 16.4, Chrome 111 and Firefox 114. This could matter on old iOS devices and is untested.
- **Ammo selector:** the `return` parameter now only accepts profile pages, with or without a locale prefix, and anything else goes to `/profiles`. Kit 3's `goto` rejects unknown paths, so a crafted link left the selection button doing nothing. The check is `safeReturnPath` in [`profileOps.js`](../src/lib/utils/profileOps.js).

## For developers

This changes daily work.

- **Config:** `svelte.config.js` is gone. Its config is in `sveltekit({...})` in [`vite.config.js`](../vite.config.js), including the Capacitor `bundleStrategy` branch.
- **`$lib` is now `#lib`**, through `imports` in [`package.json`](../package.json). Paraglide imports need `.js`.
- **`$app/environment` is now `$app/env`.**
- **`goto`** uses `replace` instead of `replaceState`.
- **`jsconfig.json`** extends `$app/tsconfig`.
- **Node** must be at least 22.22.2, the `jsdom` floor, which `engine-strict` in `.npmrc` enforces. `jsdom` accepts `^22.22.2 || ^24.15.0 || >=26.0.0`.
- **`sv migrate sveltekit-3` was not used:** on a scratch copy it dropped the Capacitor branch.

### Tests

**417 passed, 1 todo.** `build` and `build:mobile` pass, and `npm ci` on stock npm 10 leaves the lockfile unchanged. The workflows needed no change. The test run and `npm audit` were rerun for this document; the builds and browser checks were not.

Mock tests still bite: 7 mutants plus a control failed the same tests on Vitest 4 and 5.

Browser smoke test against `origin/develop`: 48 of 49 on `vite preview` and the static host, and 49 of 49 on the mobile build, against 48 or 49 on `develop`.

- Text, chart data, PDF hashes and `lang` match.
- 60 of 60 screenshots are pixel-identical.
- 12 extra Kit 3 checks pass on every target.

The one failing check is an aborted ApexCharts chunk request on a deep reload, seen on both builds, with charts still rendering. Its cause is unknown. This corrects #71's explanation that the script left the page.

## Deployment notes

Nothing to run or configure on the server. Local checkouts need Node 22.22.2 or later and a fresh `npm ci`.

## Security review

**PASS.**

- `return` cannot leave the origin.
- No server-only code in the client bundle.
- No source maps or env values in the build.
- The lockfile is clean.

**Pre-existing, left for [#76](https://github.com/hawkins48b/cw-zro/issues/76):** `electron` advisories in the shipped desktop runtime, and no `setWindowOpenHandler` or `will-navigate` guard in `electron/main.js`.
