# ApexCharts 8.8.1

- **Date:** 2026-11-12
- **Branch:** task/75-apexcharts-8
- **Issue:** [#75](https://github.com/hawkins48b/cw-zro/issues/75)
- **Status:** Not in production yet

## Summary

ApexCharts goes from 5.16.0 to exactly 8.8.1, with no caret. It draws the Ballistic, MPBR, Compare and Trajectory Validation charts. No calculated result changed, and no baseline or calculation file was touched.

**Release notes:**

- Charts use ApexCharts 8.8.1. The Max Drop label on the Ballistic chart is no longer cut off at the right edge.
- Chart pages download about 116 kB more (gzipped).

## Changes

| Area | Change |
|------|--------|

Its licence is the ApexCharts text with "Apex Commons" in place of "ApexCharts", without the premium section. It makes no network calls, has no `eval` and does not touch storage |
| Compare chart | ApexCharts 8.4.0 and later shows series names as text in the legend and escapes them in the tooltip. The app's own escaping (#103) would have shown `&amp;amp;` and `&amp;lt;`, so the chart now gets the plain name (`compareSeriesText`). `compareSeriesName` and `escapeHtmlText` are removed, as is the #111 aria-label repair (`chartLabelText`, `chartLabelSeries` and the `MutationObserver`). The translated chart description stays |

ApexCharts writes their output as HTML, which would bring back the XSS of #103. The mobile build has no Content-Security-Policy (#135) to stop it |

Breaking changes from 6.0.0 to 8.8.1 that were checked:

- 7.0.0 and 8.0.0 moved features out of the default bundle. The app uses none of them.
- Since 6.5.0 premium features show a watermark without a licence key. The app uses none, and no watermark appeared.
- 8.5.0 moved `min-height` from the host element to `.apexcharts-canvas`. No visible effect.
- Every option the app sets still exists in 8.8.1.

## Content-Security-Policy and privacy

The policy (`csp` in `vite.config.js`) is unchanged. ApexCharts 8.8.1 and apex-commons have no `eval` or `new Function`. The `style` attributes in tooltip HTML were already covered by `style-src 'unsafe-inline'`. The bundle holds two `fetch` calls that embed fonts in chart exports. The app never starts an export, because the toolbar is hidden. `https://apexcharts.com/pricing` appears only in a console warning for paid features.

## Lazy loading and size

The chart code is still its own chunk, loaded by `await import('apexcharts')` in `onMount` of the four chart pages. It grows from 604 kB (165 kB gzipped) to 950 kB (280 kB gzipped). The "chunk over 500 kB" build warning was already there.

## Tests

- New `src/test/apexcharts.test.js` (9 tests) renders the real 8.8.1 browser build in jsdom. It checks the exact pin; hostile names shown as typed in the legend, legend aria-labels and tooltip, with no element created; the chart description; at most 121 x-axis labels for the tick cap; the annotation labels; and the formatter guard. The tick cap, annotation and formatter tests were broken on purpose and failed.
- The tests of the removed helpers were dropped from `compareEntries.test.js` and `format.test.js`.
- `npm run test:run`: 3935 passed, 1 todo, in 35 files. `npm run build` and `npm run build:mobile` pass. `npm run audit:check` passes (6 moderate, 4 low, as on `develop`, none from ApexCharts).

## Browser check

Production builds of this branch and of `origin/develop`, in Chromium, behind a static server with SPA fallback: 49 checks, 49 passed on both. No console error or warning, no failed request, no CSP violation.

- Ballistic (elevation and velocity, light and dark), MPBR (in, cm, 20 in target), Compare, Trajectory Validation.
- Axis titles, annotation labels (the MPBR Max. Ordinate label included), legends and series match `develop`.
- Axis titles follow every unit switch: yd/m, in/cm, fps/m/s, the compare y-axis (#10).
- 2000 yd with a step of 1 draws 121 x-axis labels.
- A profile name with markup shows as typed in the compare legend, aria-labels and tooltip, with hover and legend toggle. No element is created and no script runs.

Differences from 5.16.0 seen in the browser:

- The Max Drop label was cut off at the right edge and is now drawn whole.
- At 2000 yd four tick labels read 833, 883, 933 and 983 instead of 834, 884, 934 and 984. These are axis positions, not calculated results.

**Not checked:** the Electron and mobile runtimes, the French and German pages, a phone-width viewport.

## Security review

PASS. Every place a series name reaches in ApexCharts 8.8.1 is written as text, or escaped by `nameAsHtml` before it is written as HTML, so this does not depend on the CSP. Two low points were fixed in the branch: the formatter guard above, and `apex-commons` added to the Dependabot exclusion.
