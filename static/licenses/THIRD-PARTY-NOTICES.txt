Replacing bclibc
----------------

1. Get the js-ballistics source at tag v3.1.0 (commit
   b71066fd5b80f1ee9b790a6b35a89bfd28a16315), with its lib/bclibc
   submodule (bclibc v2.0.0), and change bclibc as you wish.
2. Build js-ballistics as its README explains ("make build"). This compiles
   bclibc to WebAssembly and embeds it in the js-ballistics bundle.
3. Install that js-ballistics package in a checkout of ZRO and build ZRO
   again: "npm run build" (web), "npm run build:mobile" (Android, iOS) or
   "npm run electron:build" (desktop).

The full steps are in docs/development.md of the ZRO repository, section
"Replacing the bclibc engine".
